# Задачи и их статус

| Работа | Основные файлы | Статус | Что проверяется |
|---|---|---|---|
| Задача 1: меню и бизнес | `bot/menu.py`, `bot/business.py` | Готово | интерфейс `/start`, два бизнеса, профиль, настройки, поиск, избранное и связанная логика |
| Задача 2: модели и JSON | `models.py`, `storage.py` | Готово | интерфейс  моделей, транзакции, JSON и разделение бизнесов |
| Задача 3: сборка и запуск | `main.py`, `config.py`, `repository.py` | В процессе разработки | конфигурация, сборка зависимостей, запуск polling и контракт хранения |
| Задача 4: общий Telegram-слой, Catalog и правила | `bot/common.py`, `logic/catalog.py`, `logic/rules.py` | В процессе разработки | middleware, общие формы, сервисные методы двух бизнесов и проверка пользовательского ввода |
| Задача 5: услуги и доступность | `bot/services.py`, `bot/schedule.py`, `bot/calendar.py`, `logic/availability.py` | Запланировано | услуги, недельный шаблон, исключения дат, календарь и свободные слоты |
| Задача 6: запись и визит | `bot/booking.py`, `bot/appointments.py`, `bot/notifications.py`, `logic/booking.py` | Запланировано | создание, перенос, отмена, длительность, предоплата и напоминания |
| SQL Server | `database/`, `alembic/`, `tests/database/` | Запланировано | ORM, ограничения, миграции и транзакции |

Участник работает в своей ветке, запускает проверки и передаёт изменение через Pull Request. Основная ветка
`main` объединяется только после просмотра изменений и проверки сценария.
